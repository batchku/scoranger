# Photographs of 0.7.4 build 191

Taken by `ScorangerUITests/DesignerSweep` on 2026-09-10 and exported from the
result bundle. `L-*` are iPad landscape (rotated upright from the sweep's raw
portrait framebuffer with `sips -r -90`), `P-*` iPad portrait; the `70-`
series is at large Dynamic Type; `60-` are empty states; `80-`/`90-` are
edge cases.

**Names are the sweep's step labels, not a guarantee of content.** The sweep
never stops early -- a step whose control did not appear photographs whatever
was on screen -- so a file can carry a step's name and show the previous
screen. Trust the picture over the filename.
